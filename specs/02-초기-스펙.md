# 초기 스펙

## 제품 구성

컨셉은 **다음에 소비할 대상에 대한 연결**이다.
기록은 선택의 근거를 남기고, 접근 방법은 선택한 콘텐츠의 실제 감상으로 이어지게 한다.

기본 기능은 콘텐츠 기록·편집·목록·상세 조회다.
재미 요소로 `Surprise me`를 제공해, 사용자가 모은 콘텐츠와 감상 기록을 바탕으로 다음에 소비할 대상을 제안한다.

대상은 영화·드라마·책·음악·글·팟캐스트다.
디자인 시스템은 이 문서와 별도로 정의한다.

## 기본 기록

콘텐츠 하나에 감상 전후의 기록을 함께 보관한다.

1. **제목과 종류:** 기록할 콘텐츠를 식별한다.
2. **상태:** `will consume` 또는 `consumed`로 구분한다. 감상한 콘텐츠도 바로 기록할 수 있다.
3. **발견한 출처:** 어디서 접했는지 글·영상·추천 등의 설명과 링크를 남긴다.
4. **관심이 생긴 이유:** 왜 보고·읽고·듣고 싶어졌는지 남긴다.
5. **접근 방법:** 재생·열람·구매 등 실제 감상에 접근할 링크나 안내를 남긴다. 발견한 출처와 구분한다.
6. **감상 후 기록:** 감상과 생각을 남긴다. 감상 완료를 긍정적인 평가로 간주하지 않는다.
7. **예상 소요 시간:** 알고 있을 때 선택적으로 남긴다. 전체 길이와 실제 감상할 시간은 다를 수 있다.

초기 입력안에서는 제목·종류·상태만 필수로 두고 나머지는 선택 사항으로 둔다.
기록한 내용은 이후 수정할 수 있으며, 상태를 바꿔도 기존 출처와 관심 이유는 유지한다.
생성·수정 시각은 앱이 저장한다.

## 목록과 상세

1. 목록에서 저장한 콘텐츠를 조회하고 종류와 상태로 좁혀 볼 수 있다.
2. 항목에는 제목·종류·상태와 기록된 관심 이유를 보여준다.
3. 상세에서 발견한 출처·관심 이유·접근 방법·감상 후 기록을 함께 확인한다.
4. 상세에서 기록을 편집하거나 저장된 접근 링크를 열 수 있다.

## Surprise me

사용자가 직접 실행하면 보관함에서 콘텐츠 하나와 짧은 추천 이유를 제안한다.
외부의 새 콘텐츠를 검색하는 기능이 아니라, 사용자가 모은 기록을 다시 발견하는 기능이다.

1. **현재 상황:** 가용 시간과 집·이동 중·밖 같은 상황을 선택적으로 입력한다. 초기에는 GPS 자동 수집 대신 직접 선택하는 방식을 사용한다.
2. **추천 근거:** `will consume`의 관심 이유와 출처, `consumed`의 감상 기록, 현재 상황을 활용한다. 감상한 콘텐츠의 재감상도 후보가 될 수 있다.
3. **뜻밖의 선택:** 조건에 맞는 후보 중 오래된 기록이나 최근 선택과 다른 콘텐츠도 고려한다. 항상 최신 항목이나 가장 비슷한 항목만 고르지 않는다.
4. **결과:** 콘텐츠 하나, 저장된 기록에 근거한 짧은 이유, 접근 방법을 보여준다. 다른 제안을 요청할 수 있다.
5. **정보 부족:** 소요 시간이나 접근 방법이 없으면 알 수 없는 것으로 취급한다. 모델이 길이·이용 가능 서비스·링크를 만들어내지 않는다.
6. **후보 없음:** 저장된 콘텐츠가 없거나 입력 조건에 맞는 후보가 없으면 그 상태를 알린다. 조건 변경이나 기록 추가로 이어질 수 있게 한다.

추천을 받거나 접근 링크를 열었다는 이유만으로 `consumed`로 변경하지 않는다.

## 온디바이스 AI

외부 모델 API 대신 기기에 제공되는 온디바이스 모델을 우선 사용한다.

1. 앱이 시간·상황과 기록으로 후보를 좁힌다.
2. 후보의 식별자와 필요한 기록만 모델에 전달한다. 전체 보관함을 매번 전달하지 않는다.
3. 모델이 전달받은 후보 중 하나를 선택하고 기록에 근거한 이유를 작성한다.
4. 앱이 결과의 식별자를 검증하고, 제목과 접근 링크는 원본 기록에서 표시한다.
5. 모델 미지원·미준비·오류 시에는 조건 기반 추첨으로 제안하고, 저장된 관심 이유를 함께 보여준다.

연결 대상은 iOS의 Foundation Models 온디바이스 모델과 Android의 ML Kit GenAI Prompt API다.
Flutter에서 각 플랫폼의 네이티브 API를 연결하며, 실행 시 사용 가능 여부를 확인한다.
지원 기기·OS·언어와 모델 준비 상태에 따라 AI 기능의 사용 가능 여부가 달라진다.
한국어 추천 품질과 응답 속도는 실제 기기에서 검증해야 하며, 현재 구현·검증된 기능은 아니다.

## 초기 범위에서 제외

1. 일반 목적의 AI 채팅과 외부 콘텐츠 검색·추천
2. 외부 클라우드 모델로의 자동 전환
3. GPS 위치 자동 수집과 백그라운드 AI 추천
4. 콘텐츠 자동 수집과 앱 내부의 콘텐츠 재생·열람 기능
5. 업무·관계·맛집 기록과 공개형 소셜 기능

## 설계 시 검증할 가정

1. 제목·종류·상태만으로도 빠르게 기록할 수 있고, 출처와 이유는 나중에 보충할 수 있다.
2. 시간·상황 선택이 추천의 유용성을 높이면서 입력 부담을 과도하게 늘리지 않는다.
3. 자신의 보관함에서 나온 뜻밖의 제안과 추천 이유가 실제 감상 선택으로 이어진다.
